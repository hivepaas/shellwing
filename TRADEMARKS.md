# The shellwing name and logo

shellwing's code is free software under the GPL (see [LICENSE](LICENSE)). The
name **shellwing** and its logo are trademarks of HivePaaS, and the GPL does
not cover them.

- You may use the name to say what something is or works with: "a fork of
  shellwing", "themes for shellwing", "shellwing on Arch Linux".
- Builds of this repository's code without changes may keep the name and logo.
- A modified version you distribute needs a name and an icon of its own, and
  must not suggest that HivePaaS made, checked or endorses it.

Questions, or a use not covered here: open an issue.

## Others' marks

The operating systems' and cloud providers' marks a host's tile can show
(Ubuntu, Debian, Google Cloud, DigitalOcean and the others) are their owners'
trademarks, shown only to say which system a host runs, or where. Where they
come from: [crates/app/assets/icons/os](crates/app/assets/icons/os/README.md)
and [crates/app/assets/icons/cloud](crates/app/assets/icons/cloud/README.md).
Windows, Amazon Web Services, Microsoft Azure, Oracle Cloud and IBM Cloud are
named, never shown by their marks.
