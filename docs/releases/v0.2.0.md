The second release of shellwing: it reads `~/.ssh/config` as `ssh` does, opens without a warning on macOS, and takes the security fixes in Ghostty 1.4.0.

## Upgrade notes

- **macOS 13 or later is now required.** v0.1.0 said macOS 11, but the terminal engine it was built with already needed 13.
- **`Match` blocks now count.** Before, the lines under a `Match` that did not hold were applied to the `Host` above it, so a host could connect with the wrong user, port, key or jump host. If a host of yours behaves differently after this update, check its `Match` blocks: it now gets what `ssh -G` says.
- **A host that names a key now offers only that key,** as the documentation always said. Before, every key in the agent came first.

## Security

- **Ghostty 1.4.0** for the terminal, with its security fixes, among them GHSA-w9q4 (clearing the screen with no history kept).

## SSH, the way OpenSSH does it

- **`ProxyCommand`:** reach hosts through `aws ssm start-session`, `cloudflared access ssh`, `ssh -W` and the like. A host can have its own command in `hosts.toml` or the host editor, synced with it.
- **Agents:** `IdentityAgent` reaches the agents of 1Password, Secretive and Bitwarden, and `IdentitiesOnly` keeps the others out. The key an `IdentityFile` names goes first, even as a `.pub` alone, so many keys in an agent no longer use up a server's tries.
- **Security keys** (FIDO2: `ed25519-sk`, `ecdsa-sk`) sign in through an ssh-agent.
- **X11 forwarding:** `ForwardX11`, trusted or not, or *X11 windows* in the host editor. The server only ever sees a made-up cookie.
- **`Match` blocks:** `host`, `originalhost`, `user`, `localuser`, `exec`, `tagged`, `command`, `all` and `final`. Not yet: `localnetwork`, `canonical`, `version`.
- **The session:** `RemoteCommand`, `RequestTTY`, `SendEnv` and `SetEnv`.
- **The connection:** `StrictHostKeyChecking` and `UserKnownHostsFile` for each host, and `ConnectTimeout`.
- **Exit codes:** `exit 7` on a real OpenSSH server now shows as `session closed (exit 7)`.

## Also new

- **Five more languages:** Traditional Chinese, Indonesian, Turkish, Italian and Ukrainian, which makes 15.
- **The palette** finds the snippet library's commands you have not added yet.
- **Lock shellwing when away** asks the system that it is you (Windows Hello, Touch ID).
- **Linux:** the interface uses your desktop's font, one that has Vietnamese.
- **Git sync:** commits no longer name the device, and a public repository is asked about first.
- **Touch ID** can open the vault, now that the app is signed.
- Fixes in the host editor and host list: long names and labels stay within their edges.

## The first time it opens

- **macOS**: signed and notarized, so it opens without a question.
- **Windows**: this release is not signed. SmartScreen says *Windows protected your PC*: **More info › Run anyway**.
- **Linux**: make the AppImage executable (`chmod +x`) and run it; where FUSE is missing, run it with `--appimage-extract-and-run`.
