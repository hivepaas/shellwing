The first release of shellwing: a fast, native SSH client for macOS, Windows and Linux, in a GPU-rendered terminal built with Rust and Zig.

## What's in it

- **A native terminal** on [libghostty-vt](https://ghostty.org), parsing on its own thread: smooth under heavy output, sharp at any HiDPI scale, input methods composing at the cursor.
- **SSH the way OpenSSH does it**: `~/.ssh/config` (aliases, `ProxyJump`, forwards, identity files), `known_hosts`, agent keys, key files, certificates, keyboard-interactive and two-factor codes, agent forwarding.
- **Tabs and split panes**, typing into every pane at once, and a **local terminal** beside the SSH tabs.
- **SFTP**: browse, upload and download (drag and drop too), and edit remote files in your own editor.
- **Port forwarding**: local, remote and SOCKS.
- **Saved hosts** with groups, colors, favorites, tags and jump hosts, and a command palette to find anything.
- **Snippets** and a **library of about 250 ready commands**; **environments** loaded into a shell when you choose; **config files** placed on a host until the tab closes; **notes** in Markdown.
- **An encrypted vault** for passwords, keys, snippets, environments, config files and notes, unlocked by the system keychain, Windows Hello, Touch ID or a passphrase.
- **Sync** through a synced folder, WebDAV, S3-compatible storage or a Git repository, end-to-end encrypted, with a recovery key and device pairing.
- **69 themes** (20 of them gradients), light and dark, and the interface in **10 languages**.
- **Updates**: the app tells you when a newer version is out and, from the AppImage, the `.app` or the installer, installs it when you say so.

## The first time it opens

This release is not signed with an Apple Developer ID or a Windows certificate yet, so each system asks once:

- **macOS**: drag shellwing to Applications and open it; macOS says it cannot check it. Go to *System Settings › Privacy & Security*, choose **Open Anyway** beside shellwing, and confirm (on macOS 14 and older, Control-click › **Open** does the same). Unlocking the vault with Touch ID needs an app signed by a developer, so it waits for a signed release: the keychain or the passphrase open it meanwhile.
- **Windows**: SmartScreen says *Windows protected your PC*: **More info › Run anyway**.
- **Linux**: make the AppImage executable (`chmod +x`) and run it; where FUSE is missing, run it with `--appimage-extract-and-run`.
