# 新しいノート

**Markdown** で書きます。入力しながら表示されます。記号 (`**`、`#`) はカーソルのある行にだけ表示されます。

## ノートに書けるもの

- **太字**、*斜体*、~~取り消し線~~、`コード`
- このようなリスト: Enter で続け、Tab で項目を字下げ
- [ ] タスク: ボックスをクリックするとチェック
- 表、[shellwing](https://github.com/hivepaas/shellwing) のようなリンク、引用:

> 引用。誰かの言葉や、忘れてはいけないことに。

## コマンド

コードブロックはコマンドをそのまま保ちます。ポインターを合わせると、**コピー** でクリップボードへ、**挿入** でメインウィンドウの選択中のペインへ Enter なしで入力します。そこで確認してから実行できます。

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

テキストを選択するとさらに: **… に挿入** で選択部分をシェルへ、ほかの項目で書式を整えます。*プレビュー* では変更せずに読めます。

これをすべて消して、自分のノートを書きましょう。
