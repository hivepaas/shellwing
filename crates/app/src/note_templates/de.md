# Eine neue Notiz

Schreibe in **Markdown**: Es erscheint beim Tippen. Seine Zeichen (`**`, `#`) zeigen sich nur in der Zeile mit dem Cursor.

## Was eine Notiz enthalten kann

- **Fett**, *kursiv*, ~~durchgestrichen~~ und `Code`
- Listen wie diese: Enter führt sie fort, Tab rückt einen Eintrag ein
- [ ] Aufgaben: Ein Klick auf das Kästchen hakt sie ab
- Tabellen, Links wie [shellwing](https://github.com/hivepaas/shellwing) und Zitate:

> Ein Zitat, für das, was jemand gesagt hat, oder was nicht vergessen werden soll.

## Befehle

Ein Codeblock bewahrt einen Befehl so, wie er ist. Zeige darauf: **Kopieren** legt ihn in die Zwischenablage, **Einfügen** tippt ihn in den ausgewählten Bereich des Hauptfensters, ohne Enter, damit du ihn dort liest und ausführst.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

Markiere beliebigen Text für mehr: **In … einfügen** bringt die Auswahl in die Shell, der Rest formatiert sie. *Vorschau* liest die Notiz, ohne sie zu ändern.

Lösche all das und schreibe deine eigene.
