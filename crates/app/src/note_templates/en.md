# A new note

Write in **Markdown**: it shows as you type. Its marks (`**`, `#`) show on the line the caret is on, and nowhere else.

## What a note can hold

- **Bold**, *italic*, ~~struck~~ and `code`
- Lists like this one: Enter carries them on, Tab moves an item in
- [ ] Tasks: a click on the box ticks it
- Tables, links such as [shellwing](https://github.com/hivepaas/shellwing), and quotes:

> A quote, for what someone said, or what not to forget.

## Commands

A code block keeps a command as it is. Point at it: **Copy** puts it on the clipboard, **Insert** types it into the focused pane of the main window, without Enter, to read it there and run it.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

Select any text for more: **Insert into …** puts the selection into the shell, and the rest formats it. *Preview* reads the note without changing it.

Delete all this and write your own.
