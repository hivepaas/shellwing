# Catatan baru

Tulis dalam **Markdown**: hasilnya tampil saat Anda mengetik. Tandanya (`**`, `#`) hanya tampil di baris tempat kursor berada.

## Isi sebuah catatan

- **Tebal**, *miring*, ~~dicoret~~ dan `kode`
- Daftar seperti ini: Enter melanjutkannya, Tab memasukkan butir ke dalam
- [ ] Tugas: klik kotaknya untuk mencentang
- Tabel, tautan seperti [shellwing](https://github.com/hivepaas/shellwing), dan kutipan:

> Kutipan, untuk ucapan seseorang, atau hal yang tak boleh dilupakan.

## Perintah

Blok kode menyimpan perintah apa adanya. Arahkan penunjuk ke blok itu: **Salin** menaruhnya di papan klip, **Sisipkan** mengetiknya ke panel yang aktif di jendela utama, tanpa Enter, agar dibaca dulu lalu dijalankan.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

Pilih teks apa pun untuk opsi lain: **Sisipkan ke …** memasukkan pilihan ke shell, sisanya untuk memformat. *Pratinjau* membaca catatan tanpa mengubahnya.

Hapus semua ini dan tulis catatan Anda sendiri.
