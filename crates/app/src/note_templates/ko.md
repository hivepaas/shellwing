# 새 노트

**Markdown**으로 작성하세요. 입력하는 대로 표시됩니다. 기호(`**`, `#`)는 커서가 있는 줄에만 보입니다.

## 노트에 담을 수 있는 것

- **굵게**, *기울임*, ~~취소선~~, `코드`
- 이런 목록: Enter로 이어 가고, Tab으로 항목을 들여 씁니다
- [ ] 할 일: 상자를 클릭하면 체크됩니다
- 표, [shellwing](https://github.com/hivepaas/shellwing) 같은 링크, 인용:

> 인용. 누군가 한 말이나 잊으면 안 되는 것을 위해.

## 명령

코드 블록은 명령을 그대로 보관합니다. 포인터를 올리면 **복사**는 클립보드에 복사하고, **삽입**는 기본 창에서 선택된 창에 Enter 없이 입력해 그곳에서 확인하고 실행할 수 있게 합니다.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

텍스트를 선택하면 더 많은 기능: **…에 삽입**는 선택한 부분을 셸에 넣고, 나머지는 서식을 지정합니다. *미리 보기*는 노트를 바꾸지 않고 읽습니다.

이 내용을 모두 지우고 직접 작성해 보세요.
