# 新筆記

用 **Markdown** 撰寫：輸入時即可看到效果。標記（`**`、`#`）只在游標所在的行顯示。

## 筆記可以包含什麼

- **粗體**、*斜體*、~~刪除線~~ 和 `程式碼`
- 像這樣的清單：Enter 延續，Tab 縮排項目
- [ ] 待辦事項：點一下方框即可勾選
- 表格、連結（如 [shellwing](https://github.com/hivepaas/shellwing)）以及引言：

> 引言，用來記下某人說過的話，或不能忘記的事。

## 指令

程式碼區塊會原樣保存指令。將指標移上去：**複製** 會複製到剪貼簿，**插入** 會將其輸入到主視窗中目前的窗格，不按 Enter，方便在那裡查看後再執行。

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

選取任意文字可做更多：**插入到 …** 把選取內容送入 shell，其餘選項用於設定格式。*預覽* 可以只讀而不修改筆記。

刪除這些內容，寫下你自己的筆記。
