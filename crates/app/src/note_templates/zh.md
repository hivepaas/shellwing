# 新笔记

用 **Markdown** 书写：输入时即可看到效果。标记（`**`、`#`）只在光标所在的行显示。

## 笔记可以包含什么

- **粗体**、*斜体*、~~删除线~~ 和 `代码`
- 像这样的列表：Enter 继续，Tab 缩进条目
- [ ] 任务：点击方框即可勾选
- 表格、链接（如 [shellwing](https://github.com/hivepaas/shellwing)）以及引用：

> 引用，用来记下某人说过的话，或不能忘记的事。

## 命令

代码块会原样保存命令。将指针移上去：**复制** 复制到剪贴板，**插入** 将其输入到主窗口中选中的窗格，不按 Enter，便于在那里查看后再运行。

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

选中任意文字可做更多：**插入到 …** 把选中内容送入 shell，其余选项用于设置格式。*预览* 可以只读而不修改笔记。

删除这些内容，写下你自己的笔记。
