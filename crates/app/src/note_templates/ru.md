# Новая заметка

Пишите в **Markdown**: он виден по мере ввода. Его значки (`**`, `#`) видны только в строке с курсором.

## Что может быть в заметке

- **Жирный**, *курсив*, ~~зачёркнутый~~ и `код`
- Списки, как этот: Enter продолжает их, Tab сдвигает пункт
- [ ] Задачи: щелчок по квадратику отмечает её
- Таблицы, ссылки вроде [shellwing](https://github.com/hivepaas/shellwing) и цитаты:

> Цитата — для чьих-то слов или того, что нельзя забыть.

## Команды

Блок кода хранит команду как есть. Наведите на него: **Копировать** копирует её в буфер обмена, **Вставить** вводит её в выбранную панель главного окна, без Enter, чтобы прочитать и запустить там.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

Выделите любой текст, чтобы сделать больше: **Вставить в …** отправляет выделенное в оболочку, остальное форматирует его. *Предпросмотр* показывает заметку, не меняя её.

Удалите всё это и напишите свою.
