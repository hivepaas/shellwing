# Cloud providers' marks

The paths in these files come from [Simple Icons](https://simpleicons.org)
16.27.1, which publishes them under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md):
each file is the icon's one path, its `<title>` left out. The names and marks
are their owners' trademarks; shellwing shows them only to say where a host
runs, and only when its user chooses one.

Amazon Web Services, Microsoft Azure, Oracle Cloud and IBM Cloud are not
among them: Simple Icons does not carry their marks, at their owners'
request. Their tiles show their names in type instead (`host_icons.rs`).
