# Operating systems' marks

The paths in these files come from [Simple Icons](https://simpleicons.org)
16.38.1 (`npm pack simple-icons@16.38.1`), which publishes them under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md):
each file is the icon's one path, its `<title>` left out. The names and marks
are their owners' trademarks; shellwing shows them only to say which system a
host runs.
