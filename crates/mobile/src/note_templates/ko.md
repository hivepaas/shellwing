# 새 노트

**Markdown**으로 작성하세요. `**`, `#` 같은 몇 가지 기호로 글자에 서식을 줍니다. 위쪽의 **미리 보기**는 읽을 때의 모습을 보여 주고, **편집**으로 돌아옵니다.

## 노트에 담을 수 있는 것

- **굵게**, *기울임*, ~~취소선~~, `코드`
- 이런 목록
- [ ] 할 일: 상자를 탭하면 체크됩니다
- 표, [shellwing](https://github.com/hivepaas/shellwing) 같은 링크, 인용:

> 인용. 누군가 한 말이나 잊으면 안 되는 것을 위해.

## 명령

코드 블록은 명령을 그대로 보관합니다. **복사**는 클립보드에 복사합니다.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

세션에서는 메뉴의 **노트…**에 노트가 나오고, 그 호스트의 노트가 먼저 옵니다. 노트의 호스트는 노트 메뉴의 **사용 호스트…**에서 고릅니다. 거기서 **삽입**은 코드 블록을 Enter 없이 셸에 입력해 그곳에서 확인하고 실행할 수 있게 합니다.

이 내용을 모두 지우고 직접 작성해 보세요.
