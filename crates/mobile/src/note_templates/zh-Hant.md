# 新筆記

用 **Markdown** 撰寫：`**`、`#` 等幾個標記即可設定文字格式。頂端的 **預覽** 顯示筆記讀起來的樣子，**編輯** 返回撰寫。

## 筆記可以包含什麼

- **粗體**、*斜體*、~~刪除線~~ 和 `程式碼`
- 像這樣的清單
- [ ] 待辦事項：輕觸方框即可勾選
- 表格、連結（如 [shellwing](https://github.com/hivepaas/shellwing)）以及引言：

> 引言，用來記下某人說過的話，或不能忘記的事。

## 指令

程式碼區塊會原樣保存指令：**複製** 會將其複製到剪貼簿。

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

在工作階段中，選單裡的 **筆記…** 會列出你的筆記，適用於該主機的排在最前：在筆記選單的 **適用主機…** 中選擇它的主機。在那裡，**插入** 會把程式碼區塊輸入到 shell，不按 Enter，方便查看後再執行。

刪除這些內容，寫下你自己的筆記。
