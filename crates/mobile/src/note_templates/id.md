# Catatan baru

Tulis dalam **Markdown**: beberapa tanda, seperti `**` dan `#`, membentuk teks. **Pratinjau**, di bagian atas, menampilkan catatan seperti saat dibaca, dan **Edit** kembali menulis.

## Isi sebuah catatan

- **Tebal**, *miring*, ~~dicoret~~ dan `kode`
- Daftar seperti ini
- [ ] Tugas: ketuk kotaknya untuk mencentang
- Tabel, tautan seperti [shellwing](https://github.com/hivepaas/shellwing), dan kutipan:

> Kutipan, untuk ucapan seseorang, atau hal yang tak boleh dilupakan.

## Perintah

Blok kode menyimpan perintah apa adanya: **Salin** menaruhnya di papan klip.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

Dalam sesi, **Catatan…** di menunya menampilkan catatan Anda, yang untuk host-nya lebih dulu: **Untuk host…**, di menu sebuah catatan, memilih host-nya. Di sana, **Sisipkan** mengetik blok kode ke shell, tanpa Enter, agar dibaca dulu lalu dijalankan.

Hapus semua ini dan tulis catatan Anda sendiri.
