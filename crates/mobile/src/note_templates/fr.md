# Une nouvelle note

Écrivez en **Markdown** : quelques marques, comme `**` et `#`, mettent le texte en forme. **Aperçu**, en haut, montre la note telle qu'elle se lit, et **Modifier** y revient.

## Ce qu'une note peut contenir

- **Gras**, *italique*, ~~barré~~ et `code`
- Des listes comme celle-ci
- [ ] Des tâches : un appui sur la case la coche
- Des tableaux, des liens comme [shellwing](https://github.com/hivepaas/shellwing), et des citations :

> Une citation, pour ce que quelqu'un a dit, ou ce qu'il ne faut pas oublier.

## Commandes

Un bloc de code garde une commande telle quelle : **Copier** la met dans le presse-papiers.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

Dans une session, **Notes…** dans son menu liste vos notes, celles de son serveur d'abord : **Pour les serveurs…**, dans le menu d'une note, choisit ses serveurs. Là, **Insérer** saisit un bloc de code dans le shell, sans Entrée, pour le relire et le lancer là.

Effacez tout ceci et écrivez la vôtre.
