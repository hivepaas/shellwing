# 新笔记

用 **Markdown** 书写：`**`、`#` 等几个标记即可设置文字格式。顶部的 **预览** 显示笔记读起来的样子，**编辑** 返回书写。

## 笔记可以包含什么

- **粗体**、*斜体*、~~删除线~~ 和 `代码`
- 像这样的列表
- [ ] 任务：轻点方框即可勾选
- 表格、链接（如 [shellwing](https://github.com/hivepaas/shellwing)）以及引用：

> 引用，用来记下某人说过的话，或不能忘记的事。

## 命令

代码块会原样保存命令：**复制** 将其复制到剪贴板。

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

在会话中，菜单里的 **笔记…** 列出你的笔记，适用于该主机的排在最前：在笔记菜单的 **适用主机…** 中选择它的主机。在那里，**插入** 会把代码块输入到 shell，不按 Enter，便于查看后再运行。

删除这些内容，写下你自己的笔记。
