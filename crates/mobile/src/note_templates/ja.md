## コマンド

コードブロックはコマンドをそのまま保ちます。**コピー** でクリップボードへコピーします。

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

セッションでは、メニューの **ノート…** にノートが並び、そのホストのものが先頭に来ます。ノートのホストは、そのノートのメニューの **対象ホスト…** で選びます。そこで **挿入** を押すと、コードブロックを Enter なしでシェルに入力します。そこで確認してから実行できます。

これをすべて消して、自分のノートを書きましょう。
