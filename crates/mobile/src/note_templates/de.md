# Eine neue Notiz

Schreibe in **Markdown**: Ein paar Zeichen wie `**` und `#` formen den Text. **Vorschau** oben zeigt die Notiz, wie sie sich liest, und **Bearbeiten** führt zurück.

## Was eine Notiz enthalten kann

- **Fett**, *kursiv*, ~~durchgestrichen~~ und `Code`
- Listen wie diese
- [ ] Aufgaben: Ein Tippen auf das Kästchen hakt sie ab
- Tabellen, Links wie [shellwing](https://github.com/hivepaas/shellwing) und Zitate:

> Ein Zitat, für das, was jemand gesagt hat, oder was nicht vergessen werden soll.

## Befehle

Ein Codeblock bewahrt einen Befehl so, wie er ist: **Kopieren** legt ihn in die Zwischenablage.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

In einer Sitzung zeigt **Notizen…** in ihrem Menü deine Notizen, die für ihren Host zuerst: **Für Hosts…** im Menü einer Notiz wählt ihre Hosts. Dort tippt **Einfügen** einen Codeblock in die Shell, ohne Enter, damit du ihn dort liest und ausführst.

Lösche all das und schreibe deine eigene.
