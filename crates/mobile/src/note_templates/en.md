# A new note

Write in **Markdown**: a few marks, such as `**` and `#`, shape the text. **Preview**, at the top, shows the note as it reads, and **Edit** goes back.

## What a note can hold

- **Bold**, *italic*, ~~struck~~ and `code`
- Lists like this one
- [ ] Tasks: a tap on the box ticks it
- Tables, links such as [shellwing](https://github.com/hivepaas/shellwing), and quotes:

> A quote, for what someone said, or what not to forget.

## Commands

A code block keeps a command as it is: **Copy** puts it on the clipboard.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

In a session, **Notes…** in its menu lists your notes, those for its host first: **For hosts…**, in a note's menu, picks its hosts. There, **Insert** types a code block into the shell, without Enter, to read it there and run it.

Delete all this and write your own.
