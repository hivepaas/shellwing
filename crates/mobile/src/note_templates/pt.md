# Uma nova nota

Escreva em **Markdown**: algumas marcas, como `**` e `#`, dão forma ao texto. **Prévia**, no topo, mostra a nota como ela se lê, e **Editar** volta.

## O que uma nota pode conter

- **Negrito**, *itálico*, ~~riscado~~ e `código`
- Listas como esta
- [ ] Tarefas: um toque na caixa marca
- Tabelas, links como [shellwing](https://github.com/hivepaas/shellwing), e citações:

> Uma citação, para o que alguém disse, ou o que não esquecer.

## Comandos

Um bloco de código guarda um comando como ele é: **Copiar** o copia para a área de transferência.

```bash
sudo systemctl restart nginx
journalctl -u nginx --since "10 min ago"
```

Numa sessão, **Notas…** no menu dela lista suas notas, primeiro as do servidor dela: **Para servidores…**, no menu de uma nota, escolhe os servidores dela. Ali, **Inserir** digita um bloco de código no shell, sem Enter, para ler e rodar ali.

Apague tudo isto e escreva a sua.
